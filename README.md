# Nest 🏠

A shared living management app for roommates. Tracks expenses, groceries, chores, and a shared calendar in one place — built as a real-world React + Supabase app.

## Features

- **Dashboard** — overview of shared activity
- **Expenses** — split and track shared costs
- **Groceries** — shared shopping list
- **Calendar** — shared apartment calendar
- **Interests** — discover things your roommates are into

## Stack

- **Frontend:** React 19, Vite, React Router v7
- **Backend / Auth / DB:** Supabase (Postgres + Auth)
- **Animation:** GSAP, Framer Motion, Lottie
- **Styling:** CSS Modules

## Run locally

You'll need a Supabase project. Copy `.env.example` to `.env` and fill in your project URL and anon key.

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
